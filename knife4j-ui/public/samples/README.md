# 示例文件说明

此目录包含用于演示不同请求参数类型的示例文件：

## 文件列表

| 文件 | 类型 | 用途 |
|------|------|------|
| `sample.xml` | XML | 演示 application/xml 请求 |
| `sample.txt` | Text | 演示 text/plain 请求 |
| `sample.xlsx` | Excel | 演示 Binary 文件上传 |

## 使用方法

1. **XML 请求**：将 `sample.xml` 内容复制到请求体中
2. **Text 请求**：将 `sample.txt` 内容复制到请求体中
3. **Binary 上传**：选择 `sample.xlsx` 文件进行上传测试

## 注意事项

- 这些文件仅用于演示目的
- 实际使用时请根据业务需求修改内容
